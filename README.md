# Bridge Team Workspace

A responsive, static GitHub Pages preview of the Bridge Team Workspace screen.

## Preview

This page reproduces the simple team overview and includes navigable Board, Conversations, Tasks, Shared files, and Email views. The inbox selector switches among All inboxes, OPBWP, Business, Kizazi Fund, and BK Groups.

## Current scope

This is a front-end preview. GitHub Pages serves static files, so chat, task persistence, shared file storage, authenticated access, and live email synchronization/routing are not connected here. The email screen marks the mailbox feed as not connected. Connect the Google Workspace mailbox and confirm alias addresses/routing before treating it as a live inbox.
